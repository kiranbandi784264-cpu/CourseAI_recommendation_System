# Course Recommendation Engine & AI Study Platform

A hybrid Machine Learning Course Recommendation System combining 7 recommendation models (LightGCN Graph Neural Networks, Neural Collaborative Filtering, Content-Based Similarity, User-Based CF with VADER Sentiment, Item-Based CF, Job-Skills Gap Alignment, and Implicit Matrix Factorization).

Includes **250+ courses**, **4-Week Syllabi**, **Reference Books with purchase links**, 3D Visual Cliparts, and an **AI Study Tutor & Chatbot**!

---

## 🚀 How to Run (2 Simple Steps)

### Step 1: Install Dependencies
Open terminal/command prompt in the project folder and run:
```bash
pip install -r requirements.txt
```

### Step 2: Start the Web Dashboard
```bash
python app.py
```

Open **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser!

---

## ⚡ Optional: Run Pipeline Re-Training
To re-generate datasets or re-train all 7 ML models:
```bash
python run_pipeline.py
```
Or click the **🚀 Run Pipeline Training** button in the web interface!
